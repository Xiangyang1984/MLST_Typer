Global PubMLST OAuth token directory

This directory is shared by ALL PubMLST species/schemes.
Do not create one token directory per species.

access_token  - persistent token copied from the supplied Pneumo-Typer package
session_token - generated automatically; renewable when expired
request_token - temporary; only used when a new browser authorization is required

Token files are credentials. Keep this directory private and do not publish it.
